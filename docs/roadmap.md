# Roadmap

- **0.1 Prototype** — compilable Android layer, launcher surface, controlled terminal, DreamShell, package-manager boundary, documentation, CI.
- **0.2 Terminal + Userland** — process-safe userland APIs and richer terminal history without assuming root.
- **0.3 Package System** — signed repository index, verified package metadata, real user-space installation.
- **0.4 DreamByte UI** — mature Modern/Retro themes, widgets, settings, and app discovery.
- **0.5 Android integration** — optional public Android integrations and device compatibility work.
- **0.6 AOSP integration** — separate AOSP/device tree work, overlays, and privileged components where supported.
- **1.0 DreamByte OS M** — stable product release for DreamPhones and DreamTabs.
